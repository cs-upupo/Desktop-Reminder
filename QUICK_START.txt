桌面提醒 2.0.0 · Windows 64 位

使用方法
1. 先解压整个压缩包，双击“桌面提醒.exe”。
2. 点击“新建任务”，填写任务名称和提醒内容。
3. 循环任务按固定分钟间隔提醒。
4. 定时任务可选择“每日某时”或“指定日期”，并设置未完成时的再次提醒间隔。
5. 任务首次提醒后会显示“待完成”，此后持续提醒；手动点击“完成”才停止。
6. 每日任务完成后会自动等待次日；一次性任务完成后结束；循环任务完成后可重新开始。
7. 在“日期记录”中选择日期，可查看当日任务、完成情况和完成时间。
8. 每个任务均可独立编辑、暂停、启用、测试通知或删除。
9. 点击“打开 Windows 通知设置”可检查通知权限。
10. 点击窗口叉号会隐藏到右下角系统托盘；托盘右键“退出应用”才会完全退出。

运行条件
支持 Windows 10 / 11 64 位，需要 Microsoft Edge WebView2 Runtime。
使用者不需要安装 Go、Node 或 Wails，也不需要管理员权限。
缺少 WebView2 时，请安装微软提供的 WebView2 Evergreen Runtime。

请留意
所有提醒都是静音通知。Windows 勿扰、专注助手或通知设置可能隐藏横幅。
电脑关机时不能通知；程序在休眠后恢复时会处理已经到期的任务。
升级前请从托盘完全退出旧版本，再运行新版，避免仍显示旧窗口。
如果托盘图标没有直接显示，请点击任务栏右下角的小箭头查看隐藏图标。

数据存储
任务、运行状态和完成记录保存在当前用户的：
%APPDATA%\DesktopReminder\config.json

旧版单任务配置会自动迁移为一个暂停的循环任务。
应用无需联网，不收集或上传任务内容。
请保留 THIRD_PARTY_NOTICES.txt 中的第三方软件许可说明。
