桌面提醒 1.1.0 · Windows 64 位

使用方法
1. 先解压整个压缩包，双击“桌面提醒.exe”。
2. 输入提醒内容和间隔分钟数，点击“开始提醒”。
3. 到点会显示 Windows 桌面通知，全程无声音。
4. 点击“暂停”保留剩余时间；“继续提醒”接着计时。
5. 如需修改内容或间隔，先暂停。改变间隔后会从新的完整间隔开始。
6. 点击“测试无声通知”，可立即检查通知是否正常。
7. 点击“系统通知设置”，可直接打开 Windows 通知设置页面。
8. 点击窗口叉号会隐藏到右下角系统托盘，提醒继续运行。
9. 在托盘图标上右键，选择“打开主窗口”或“退出应用”。退出应用才会停止提醒。
   如果图标没直接显示，点任务栏右下角的小箭头查看隐藏图标。

运行条件
支持 Windows 10 / 11 64 位，需要已安装 Microsoft Edge WebView2 Runtime。
使用者不需要 Go、Node、Wails，不需要管理员权限。
如果系统缺少 WebView2，请安装微软提供的 WebView2 Evergreen Runtime 后重试。

请留意
最小化或点击叉号后继续计时；从系统托盘右键“退出应用”才会完全退出。
升级时请先完全退出旧版本，再打开新版，避免单实例机制仍显示旧窗口。
电脑关机或休眠期间不能弹出通知。运行中的程序唤醒后最多补发一条到期提醒。
程序重新打开后会恢复上次有效设置，等待手动开始。
通知由 Windows 管理，勿扰/专注助手或系统通知设置可能隐藏通知横幅。
可在 Windows“设置 → 系统 → 通知”检查“桌面提醒”的通知权限。
暂停无法撤回 Windows 已经接收或显示的通知。

数据存储
设置保存在当前 Windows 用户的 %APPDATA%\DesktopReminder\config.json。
WebView2 的界面缓存保存在当前用户的应用数据目录。
应用会在当前用户的注册表中登记通知名称 DesktopReminder.Silent。
应用无需联网，不收集或上传提醒内容。
请同时保留 THIRD_PARTY_NOTICES.txt 中的第三方软件许可说明。
