## 桌面提醒 2.0.0

这是首个通过 GitHub Releases 发布的正式版本，适用于 Windows 10 / 11 64 位。

### 新功能

- 支持创建、编辑、启用、暂停、完成和删除多个提醒任务。
- 支持固定分钟间隔的循环任务。
- 支持每天指定时分秒执行的定时任务。
- 支持指定年月日与时分秒执行的一次性任务。
- 首次提醒后可按单独的间隔持续提醒，直到手动点击完成。
- 支持按日期查看当天任务、完成数量、未完成数量及逐项状态。
- 完成记录会保留任务当时的名称和内容，删除任务后仍可查看历史。
- 点击窗口叉号隐藏到系统托盘，托盘菜单可恢复窗口或退出。
- Windows 通知保持静音，并提供系统通知设置快捷入口。
- 旧版单任务配置会自动迁移为一个暂停的循环任务。

### 下载与运行

推荐下载 `DesktopReminder-windows-amd64-v2.0.0.zip`，完整解压后双击 `桌面提醒.exe`。也可以直接下载单独的 exe。

使用者无需安装 Go、Node 或 Wails。系统需要 Microsoft Edge WebView2 Runtime；Windows 10 / 11 通常已经包含。

`SHA256SUMS.txt` 可用于核对下载文件是否完整。任务数据只保存在当前用户的 `%APPDATA%\DesktopReminder\config.json`，应用运行时无需联网。
